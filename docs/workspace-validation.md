# 学习工作区、个人资料库与教师管理

## 启动与入口

在项目根目录运行 `docker compose up -d --build`。登录页为 `http://127.0.0.1:8000/login`，学生登录后进入 `/tutor`，教师进入 `/admin`；教师可从管理页切换到学习区。`/materials` 的浏览器入口使用新资料库，原 JSON 接口保持兼容。

默认暖米白与砖红主题，左下角或管理页顶部可切换深浅主题；偏好仅保存在本机浏览器。错题本、智能批改、自主学习没有功能入口，本次不实现这些模块。

## 学生与教师的学习区

1. 左侧“智能体”切换助手，欢迎区快捷问题只填入编辑器，不会自动调用模型。首次发送才创建会话。
2. 提问框旁可选技能、本班已就绪资料、个人资料、原会话上传内容。每轮一个显式技能、最多三份资料；成功后恢复默认选择，失败保留问题与选择。
3. “仅本会话”文件在尚无会话时暂存于内存，发送时创建会话、上传并取得引用；上传部分成功后重试复用已有标识，不重复创建会话。文件不会持久化到浏览器存储。
4. 最近对话显示首条问题的简短标题、助手和最近时间，点击恢复历史。切换未发送草稿前会确认，取消可保留。

## 资料库与个人复用

- 资料库区分“本班资料”和“我的个人资料”，按学科分组，支持标题筛选、列表/网格、正文阅读。Markdown 支持标题、段落、列表、代码和安全普通链接；HTML按文本处理，不执行脚本或危险链接，不自动加载远程图片。
- 教师和学生均可直接上传个人资料，或从共享资料保存副本；也可在提问资料选择器中对原会话资料点击“存入个人库”。
- 个人资料仅保存者在本班可读，可在本人本班的多个会话中选择；同班教师无法读取学生个人资料。不自动扩展旧附件权限，不把个人内容放进共享向量库。
- 个人资料是不可变副本，重复保存同来源同正文返回现有副本。本次不提供修改/删除，以保持历史引用可读。
- 个人资料和会话附件支持 UTF-8 `.md/.txt`，最多32 KiB；资料最多12000字，技能文件最多8000字；一轮个人与会话资料总计最多18000字。个人库仅存资料，私有技能仍属于原会话。

## 教师管理台

- **学生**：本班只读名单和人数，无账号创建、密码重置或学生私人内容入口。
- **资料**：选择真实文件上传、填写学科、标题筛选、列表/网格、原文及索引状态。
- **智能体**：名称、角色、启停和默认技能/资料绑定；提示词模板保留变量预览、保存与应用。
- **技能**：内置安装、上传、新建、预览、启停与删除。MCP 引用保存时继续检查本班连接及发现缓存。
- **MCP**：登记、连接发现、断开、编辑URL/令牌及确认移除，展示工具引用与审计。编辑时令牌留空保留原值；名称不可改；连接配置变化后清缓存并要求重新连接。移除后旧审计保留，旧技能调用显示 denied。

## 分段策略与索引

自动模式保留部署默认（当前500字、80字重叠）；自定义支持空行/换行/句末，长度100–2000字、重叠0–40%和边界空白清理。预览不调用嵌入、不写库，显示总数及前20段，位置均可回溯原文。

保存班级策略只影响新上传和明确重建。旧资料继续使用其已应用版本，显示“待按当前策略重建”时可逐份执行重建。重建期间该材料暂不可检索，原文保留；失败显示 failed 并允许重试，不能视为 ready。不同材料的 ready 策略版本可同时检索；失效旧代和其他班向量结果会被服务端拒绝。模型和向量服务缺失或失败时，资料浏览及其他配置仍可使用。

## 主要接口

Swagger：`/swagger`。先登录后点击“使用当前登录鉴权”，所有业务API继续要求Bearer。

| 接口 | 用途 |
| --- | --- |
| GET `/api/me` | 当前用户与班级名称 |
| GET `/api/library/materials`、`/{id}` | 本班共享资料浏览与原文 |
| GET/POST `/api/personal-materials`、GET `/{id}` | 本人个人资料上传/复制/读取 |
| GET `/api/admin/students` | 本班只读学生名单 |
| GET `/api/admin/materials` | 索引状态、已应用策略及重建提示 |
| GET/PUT `/api/admin/index-policy` | 班级策略 |
| POST `/api/admin/index-policy/preview` | 分段预览 |
| POST `/api/admin/materials/{id}/reindex` | 指定资料重建 |
| PUT/DELETE `/api/mcp/servers/{id}` | 编辑/移除服务器 |

个人上传JSON为 `{"filename":"note.md","content":"正文","subject":"数学"}`；共享复制为 `{"source":{"kind":"shared","id":1}}`；会话复制为 `{"source":{"kind":"attachment","id":1,"conversation_id":1}}`。三种输入不可混用。

提问 `context.materials` 新增 `{"source":"personal","id":1}`；原 shared/upload 与字段缺省行为不变。个人资源跨用户/跨班、原附件跨会话以及缺失统一404；教师接口对学生403。新接口不回传MCP令牌，班级和所有者只来自鉴权。

### 2026-10-26 实测结果

- 94项Python单元测试、30项HTTP接口用例及Node SSE测试全部通过；OpenSpec严格校验、JavaScript语法检查和密钥检查通过。HTML报告和截图不提交Git。
- 浏览器验证教师五个管理分栏、模板预览/应用、技能上传/编辑/启停、资料上传/分段预览/重建、MCP发现与编辑后重新连接。学生直接进入管理页仅见权限提示；接口仍返回403。Swagger载入全部接口，使用当前教师鉴权试调策略接口返回200。
- 本人个人库上传、共享保存副本、原会话资料显式入库及跨会话选择通过。浏览器隔离测试中，两个暂存文件的第二个上传失败，修正选择后重试，仍使用同一会话和第一份附件，没有重复创建；真实应用的模型失败重试也复用原会话和个人资料。
- 1280像素桌面与390×844移动视口通过；移动菜单关闭后展开状态复原、焦点回到菜单按钮，隐藏导航不进入键盘顺序。三份资料标签可换行，无页面横向溢出；问题框按Tab进入技能按钮。浅色普通文字最低实测5.36:1，深色最低7.35:1，主题偏好刷新保留。
- **真实服务限制**：Compose主应用、Qdrant和MCP已启动。实际容器调用嵌入网关返回`GatewayUnavailable`（底层`URLError`）；真实流式模型提问两次均显示“生成失败，请重试；当前回答未完成”，未假报done。个人资料来源S1和历史落库正常，但真实嵌入/索引和完整模型回答仍待网关恢复后验收。隔离环境的索引ready和完整回答使用测试替身，不代替这两项真实验收；此前变更中的待验收项保持未完成。

## 部署前备份与回滚

本次部署前在容器持久卷创建 `/app/data/backups/before-refine-workspace/`：

- `campusclaw.db`：SQLite在线一致性备份。
- `vectors.json`：集合名称与对应快照文件清单。
- 每个集合的 `.snapshot` 文件：Qdrant在线快照的副本，原集合快照也保留。

迁移可重复执行，原共享数据、技能、绑定、会话、附件和审计保留。完整回滚须停止新应用，恢复数据库备份及清单中所有向量集合快照，再运行旧版本；不能只退代码，因为旧代码无法理解个人来源和按材料生效的索引版本。恢复前另备份新产生的数据，避免覆盖用户之后的工作。
