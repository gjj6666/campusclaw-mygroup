## Purpose

本能力用于建立师生角色、班级数据边界和教师材料入库的最小闭环，确保材料访问与知识库列表始终按登录用户所属班级在服务端隔离。

## ADDED Requirements

### Requirement: 登录角色与受保护页面访问控制
系统 SHALL 支持教师和学生两类已登录角色。系统 MUST 在用户未登录访问受保护页面时引导到登录页，且不得展示受保护页面内容。

#### Scenario: 未登录访问受保护页面
- **WHEN** 未登录用户访问材料列表、上传页面或其他受保护页面
- **THEN** 系统引导用户到登录页，并且不返回受保护页面内容

#### Scenario: 已登录用户访问受保护页面
- **WHEN** 已登录教师或学生访问其有权限的受保护页面
- **THEN** 系统允许访问，并根据用户角色和班级计算后续数据权限

### Requirement: 班级作为服务端数据边界
系统 MUST 将班级作为材料和知识库数据的访问边界。所有按班级过滤的读取 MUST 在服务端执行，客户端传入的班级标识不得扩大当前用户可访问范围。

#### Scenario: 同班用户读取本班材料
- **WHEN** 已登录用户请求材料列表
- **THEN** 系统仅返回该用户所属班级的材料和知识库条目

#### Scenario: A 班用户尝试读取 B 班材料
- **WHEN** A 班已登录用户通过 URL、请求参数或接口载荷指定 B 班材料或 B 班标识
- **THEN** 系统拒绝访问或返回空结果，并且不泄露 B 班材料内容、元数据或知识库条目

### Requirement: 教师上传材料并入库
系统 SHALL 允许教师上传其所属班级的材料。上传成功后，系统 MUST 解析材料并将解析结果写入本班知识库；本班材料列表 MUST 基于知识库查询展示。

#### Scenario: 教师上传本班材料成功
- **WHEN** 教师上传符合系统支持格式和大小限制的材料
- **THEN** 系统保存材料记录，解析材料内容，将解析结果写入该教师所属班级的知识库，并在本班材料列表中展示该材料

#### Scenario: 教师上传解析失败
- **WHEN** 教师上传材料后解析失败
- **THEN** 系统返回失败状态，不得将不完整解析结果作为可用知识库条目展示

### Requirement: 学生上传材料被拒绝
系统 MUST 拒绝学生上传材料。拒绝结果 MUST 明确表示权限不足，并且不得创建材料记录或知识库条目。

#### Scenario: 学生尝试上传材料
- **WHEN** 已登录学生提交材料上传请求
- **THEN** 系统拒绝请求，返回权限不足结果，并且不写入材料记录或知识库条目

### Requirement: 本次能力不提供课外功能
系统 MUST 不在本次能力中提供检索问答、AI 对话、作业提交与批改、注册与找回密码功能。

#### Scenario: 访问未纳入本次能力的功能入口
- **WHEN** 用户访问检索问答、AI 对话、作业提交与批改、注册或找回密码入口
- **THEN** 系统不得将这些能力作为本次变更的一部分启用
