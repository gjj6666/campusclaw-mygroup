## Purpose

本能力用于让已登录师生安全检索本人所属班级的知识库内容，并通过片段级来源信息核验结果，同时确保查询参数、索引和来源访问都不能突破班级数据边界。

## ADDED Requirements

### Requirement: 检索范围由服务端班级身份限定
系统 MUST 只允许已登录用户检索其服务端身份所绑定班级的知识库。系统 MUST NOT 使用客户端提交的班级标识扩大检索范围，也 MUST NOT 在结果、计数或错误信息中泄露其他班级的内容或元数据。

#### Scenario: 同班用户检索知识库
- **WHEN** 已登录教师或学生提交有效检索词
- **THEN** 系统仅在该用户所属班级的可检索内容中执行查询并返回结果

#### Scenario: 未登录用户发起检索
- **WHEN** 未登录用户调用知识库检索入口
- **THEN** 系统拒绝请求或引导其登录，并且不返回任何知识库结果

#### Scenario: 客户端伪造其他班级参数
- **WHEN** 已登录用户在查询参数或请求载荷中提交非本人所属班级的班级标识
- **THEN** 系统忽略该标识或拒绝请求，并且不返回目标班级的结果、数量或来源元数据

#### Scenario: 相同检索词命中多个班级
- **WHEN** 当前班级和其他班级都存在匹配相同检索词的内容
- **THEN** 系统只返回当前班级的匹配片段

### Requirement: 返回相关且状态有效的片段
系统 SHALL 将非空检索词与已完成索引且来源材料可用的知识片段进行匹配，并 MUST 按相关度从高到低返回有限数量的结果。系统 MUST NOT 返回待索引、索引失败、已失效或来源材料不可用的片段。

#### Scenario: 有匹配结果
- **WHEN** 当前班级存在与检索词相关且状态有效的知识片段
- **THEN** 系统返回不超过请求上限的结果，并按相关度从高到低排列

#### Scenario: 当前班级没有匹配结果
- **WHEN** 当前班级没有符合条件的知识片段
- **THEN** 系统返回成功响应和空结果集合，而不是返回其他班级的近似内容

#### Scenario: 提交空白检索词
- **WHEN** 用户提交空字符串或仅包含空白字符的检索词
- **THEN** 系统返回可识别的参数错误，并且不执行全库扫描或返回默认内容

#### Scenario: 命中不可检索片段
- **WHEN** 底层索引候选指向待索引、索引失败、已失效或来源材料不可用的片段
- **THEN** 系统从最终结果中排除该片段

### Requirement: 每条结果均可溯源到原始材料
系统 MUST 为每条检索结果返回内容摘要及完整来源信息。来源信息 MUST 至少包含原始材料标识、材料标题、知识片段标识和可稳定定位该片段的位置；结果中的来源关联 MUST 能由服务端权威数据验证。

#### Scenario: 查看检索结果来源
- **WHEN** 系统返回一条知识库检索结果
- **THEN** 该结果包含内容摘要、相关度、材料标识、材料标题、片段标识和片段定位信息

#### Scenario: 通过来源打开原始材料
- **WHEN** 用户从检索结果访问来源材料
- **THEN** 系统在重新校验用户身份与班级权限后返回对应原始材料

#### Scenario: 来源关联不存在或不一致
- **WHEN** 检索候选无法关联到同班级的有效知识片段和原始材料
- **THEN** 系统不返回该候选，并记录可诊断但不向用户泄露跨班内容的异常

#### Scenario: 猜测其他班级来源标识
- **WHEN** 用户修改检索结果中的材料标识或片段标识以访问其他班级来源
- **THEN** 系统拒绝访问，并且不返回该来源的内容或元数据

### Requirement: 检索索引与权威内容保持一致
系统 MUST 保留知识片段、所属班级、知识库条目和原始材料之间的权威关联。新材料只有在分片和索引全部成功后才可被检索；索引失败不得产生部分可见结果。检索后端不可用时，系统 MUST 返回明确的暂时不可用结果，而不是绕过班级过滤或返回未经验证的数据。

#### Scenario: 新材料完成索引
- **WHEN** 教师上传的材料已成功解析、分片并写入全部检索索引
- **THEN** 本班用户的后续相关查询可以命中这些片段及其来源

#### Scenario: 新材料索引失败
- **WHEN** 材料分片或任一必要索引写入失败
- **THEN** 系统将该材料的检索状态标记为失败或待重试，并且不返回其部分片段

#### Scenario: 检索后端暂时不可用
- **WHEN** 用户检索时必要的检索后端无法访问
- **THEN** 系统返回可识别的暂时不可用响应，不返回未授权或未经来源校验的降级结果

#### Scenario: 重建现有材料索引
- **WHEN** 系统对已有可用材料执行索引重建
- **THEN** 重建完成后的片段仍保持原班级和原始材料关联，且重建过程不得造成跨班级可见
