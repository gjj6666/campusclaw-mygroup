## Purpose

本能力为已登录师生提供限定本班材料的片段级知识检索。系统保存可核对的原文位置和材料来源，以关键字、向量或混合方式检索，同时确保索引故障和客户端参数都不能突破班级授权边界。

## ADDED Requirements

### Requirement: 本班正文切分与双库入库

系统 SHALL 将可用材料的正文切分为稳定、可重建的文本片段。每个片段 MUST 在关系库中保存正文、所属班级、知识库条目、原始材料、顺序及原文字符范围；对应向量 MUST 存入向量库，且向量记录可关联回该片段。任一必要索引失败时，该材料的片段不得部分进入可检索状态，原材料仍可按原有权限查看。

#### Scenario: 教师上传新材料
- **WHEN** 教师在本班上传并成功解析正文
- **THEN** 系统生成可定位的片段并完成必要索引后，本班用户可检索到这些片段

#### Scenario: 原文位置可核对
- **WHEN** 系统保存任一片段的原文起止位置
- **THEN** 该范围在原始正文中截取的文本与片段正文一致

#### Scenario: 索引中途失败
- **WHEN** 某份材料的嵌入或向量写入未全部成功
- **THEN** 系统记录可诊断的失败或待重试状态，检索结果中不出现该材料的部分片段

#### Scenario: 回填旧材料
- **WHEN** 系统对既有可用材料重复执行索引回填
- **THEN** 片段、向量和来源关系保持幂等，且仍归属原班级和原材料

### Requirement: 嵌入配置与向量维度校验

系统 MUST 仅使用服务端配置调用嵌入网关，并核对返回向量维度与配置值一致。嵌入请求 MUST 仅提交模型标识和输入文本；单次发送给模型网关的请求 MUST 不超过 20MB。API 密钥不得进入客户端资源、接口响应、日志或仓库公开配置。

#### Scenario: 正确维度的嵌入
- **WHEN** 嵌入网关返回与服务端配置维度相符的向量
- **THEN** 系统允许将该向量用于本班片段索引或查询

#### Scenario: 嵌入维度不符
- **WHEN** 嵌入网关返回的向量长度与配置值不一致
- **THEN** 系统拒绝写入或查询该向量，并返回可诊断错误，不发布错误索引

#### Scenario: 请求超过网关限制
- **WHEN** 待发送的单次网关请求超过 20MB
- **THEN** 系统拒绝该请求或先拆分为合规请求，不向网关发送超限请求

### Requirement: 关键字向量和混合检索

系统 SHALL 为已登录教师和学生提供 `keyword`、`vector` 和 `hybrid` 三种检索模式；默认模式为 `hybrid`。查询 MUST 只使用服务端当前身份所属班级，结果 MUST 在返回前根据关系库中的班级、材料可用状态、片段就绪状态和来源关系再次复核。结果 MUST 按相关度排序并受服务端上限约束；不足相关性门槛的候选不得视为命中。

#### Scenario: 三种模式检索本班内容
- **WHEN** 本班用户分别以关键字、向量或混合模式提交有效查询
- **THEN** 系统仅返回该模式下本班合格的匹配片段，并标明使用的模式

#### Scenario: 其他班级也有相同词语
- **WHEN** 另一班的材料也含有相同关键词或相近语义
- **THEN** 当前用户的结果、计数及来源中均不出现另一班的内容或元数据

#### Scenario: 伪造班级参数
- **WHEN** 客户端提交与自身身份不符的班级标识
- **THEN** 系统忽略或拒绝该标识，检索范围仍由服务端当前身份确定

#### Scenario: 空查询或非法模式
- **WHEN** 查询为空白或模式、数量参数非法
- **THEN** 系统返回明确的参数错误，不执行无边界扫描

#### Scenario: 无合格命中
- **WHEN** 当前班级没有超过相关性门槛且来源有效的片段
- **THEN** 系统返回成功响应和空结果集合，不以低相关近邻充当依据

#### Scenario: 向量依赖不可用
- **WHEN** 向量库或嵌入网关不可用且请求模式为 `vector` 或 `hybrid`
- **THEN** 系统返回明确的暂时不可用错误，不以未经声明的检索模式替代；独立的 `keyword` 模式仍可使用

### Requirement: 每个命中可回溯原文

每条结果 MUST 包含片段正文或摘要、相关度，以及由服务端验证的材料标识、标题、片段标识、顺序和原文字符范围。来源链接 MUST 重新校验当前用户的身份和班级，不能仅凭片段或材料 ID 读取其他班级原文。

#### Scenario: 查看命中出处
- **WHEN** 用户查看检索结果或点击来源
- **THEN** 系统展示可核对的原文位置，并在重新授权后允许查看对应材料正文

#### Scenario: 索引来源失效
- **WHEN** 向量候选指向不存在、跨班、未就绪或材料已不可用的片段
- **THEN** 系统丢弃该候选，不返回其正文或来源元数据

#### Scenario: 猜测其他班级来源 ID
- **WHEN** 用户直接请求另一班材料或片段的来源 ID
- **THEN** 系统拒绝访问且不泄露该来源内容
