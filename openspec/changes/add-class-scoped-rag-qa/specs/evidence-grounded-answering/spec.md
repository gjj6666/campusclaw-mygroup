## Purpose

本能力要求系统先从当前用户所属班级的有效材料中找出可核验的片段，再让生成模型基于这些片段给出简短回答与出处。没有合格证据时，系统不调用生成模型，也不输出猜测性答案。

## ADDED Requirements

### Requirement: 先检索后生成的调用门禁

系统 SHALL 提供仅限已登录用户的本班简短问答入口。系统 MUST 先执行本班检索和来源复核；只有至少一个达到相关性门槛的有效片段时，才可调用生成模型。空白问题或无合格证据时 MUST 不调用生成模型。

#### Scenario: 有本班证据
- **WHEN** 已登录用户提出问题，且本班检索得到至少一个合格片段
- **THEN** 系统仅把经授权的命中片段及其来源交给生成模型，并返回简短回答

#### Scenario: 没有本班证据
- **WHEN** 本班检索没有合格片段，即使其他班级存在相关材料
- **THEN** 系统返回空回答、空出处和“无依据”状态，且不调用生成模型

#### Scenario: 空白问题
- **WHEN** 用户提交空白问题
- **THEN** 系统返回参数错误，不发起检索或生成请求

#### Scenario: 未登录问答
- **WHEN** 请求没有有效 Bearer 身份
- **THEN** 系统拒绝问答，不返回任何班级材料或生成内容

### Requirement: 简短回答附可验证出处

生成请求 MUST 明确限制模型只使用已提供的证据片段作答，并把片段视为资料而非指令。返回的简短回答 MUST 至少关联一个由服务端复核的出处；系统不得接受模型编造的材料或片段 ID。每个出处 MUST 包含足以回到原文的位置和受保护材料链接。

#### Scenario: 回答引用有效片段
- **WHEN** 生成模型基于命中片段返回可验证的回答和引用
- **THEN** 系统返回简短回答及对应材料标题、片段 ID 和原文位置，引用可在本班材料中核对

#### Scenario: 模型输出未知引用
- **WHEN** 模型返回未提供的片段 ID、无法核验的来源或没有有效引用
- **THEN** 系统不把该内容作为有出处的回答返回，并提供可识别的失败状态

#### Scenario: 证据中包含诱导指令
- **WHEN** 检索片段内含有要求泄露密钥、忽略约束或跨班回答的文本
- **THEN** 系统仍将其作为普通资料处理，生成请求不得包含服务端密钥或其他班级资料

### Requirement: 网关故障不伪造答案

系统 MUST 仅从服务端配置读取对话模型地址、密钥和模型标识，并确保单次发送给对话网关的请求不超过 20MB。生成网关超时、拒绝或返回无效结构时，系统 MUST 返回明确的暂时不可用或生成失败状态，不得用无证据的本地猜测替代。

#### Scenario: 对话网关不可用
- **WHEN** 已有合格证据但对话网关超时或返回错误
- **THEN** 系统返回可识别的失败状态和空回答，不伪造答案

#### Scenario: 单次请求超限
- **WHEN** 问题与证据组合会使单次对话请求超过 20MB
- **THEN** 系统缩减证据或拒绝请求，不向网关发送超限请求

#### Scenario: 密钥保护
- **WHEN** 用户请求问答或查看页面资源
- **THEN** 系统不得向客户端返回嵌入或对话网关的 API 密钥
