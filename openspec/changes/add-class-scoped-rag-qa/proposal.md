## Why

现有知识库只保存整份正文，尚不能从本班讲义中找出可追溯的依据；生成模型若直接回答未见过的校内问题，可能给出缺乏证据的内容。本变更建立“切分、嵌入、入库、检索、证据约束生成”的闭环，使简短回答能够回到原文核验。

## What Changes

- 将本班已上传正文确定性切分为带原文字符范围的片段；正文和来源关系保存在关系库，向量保存在向量库，并为现有材料提供回填。
- 提供仅限当前登录用户所属班级的关键字、向量及混合检索；每个命中包含材料标题、片段位置和可重新授权访问的原文来源。
- 新增问答入口：先检索并验证命中片段，只有存在合格依据时才调用生成模型生成简短回答并标注出处；无依据时返回空回答且不调用生成接口。
- 通过服务端环境变量配置嵌入与对话网关、模型和向量维度；真实密钥写入被 Git 忽略的 `.env`，不得进入仓库、前端或响应。
- 沿用现有 Bearer 身份认证、教师上传和班级隔离；明确索引失败、网关不可用、超限请求和来源失效时的行为。

## Capabilities

### New Capabilities

- `class-scoped-knowledge-search`：本班正文切片与索引、关键字/向量/混合检索、索引一致性和原文溯源。沿用未归档变更 `add-class-scoped-knowledge-search` 的能力路径；本变更取代该旧计划作为实施来源。
- `evidence-grounded-answering`：检索先行、仅有合格证据才生成简短回答、引用来源及无依据时禁止生成。

### Modified Capabilities

- 无。主规格目录尚无已归档能力；本变更在当前材料与 Bearer 授权行为上新增独立能力。

## Impact

- 涉及 SQLite 片段及索引状态模型、材料上传流程、旧材料回填、向量库及 Docker Compose 编排。
- 涉及嵌入和对话网关客户端、服务端配置、健康检查、受保护检索和问答接口、浏览器材料页入口。
- 涉及班级隔离、索引原子可见性、检索融合、证据阈值、生成调用门禁、出处完整性和故障路径测试。
- 现有 `add-class-scoped-knowledge-search` 活动变更只覆盖检索且排除生成；实施时只执行本变更，避免两套重叠任务。
