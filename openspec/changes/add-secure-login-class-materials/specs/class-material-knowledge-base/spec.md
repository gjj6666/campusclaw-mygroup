## Purpose

本能力用于定义班级作为材料和知识库的数据边界，并建立教师上传教学材料写入知识库、本班列表可见、学生上传被拒绝的最小业务闭环。

## ADDED Requirements

### Requirement: 班级作为服务端数据边界
系统 MUST 将班级作为材料和知识库数据的访问边界。所有班级过滤 MUST 在服务端执行，客户端传入的班级标识不得扩大当前用户可访问范围。

#### Scenario: 本班材料列表查询
- **WHEN** 已登录用户请求本班材料列表
- **THEN** 系统仅返回该用户所属班级的材料和知识库记录

#### Scenario: A 班用户访问 B 班材料
- **WHEN** A 班用户通过 URL、请求参数或接口载荷访问 B 班材料
- **THEN** 系统拒绝访问，并且不返回 B 班材料内容、元数据或知识库记录

#### Scenario: 客户端传入其他班级标识
- **WHEN** 用户请求中包含非本人所属班级的班级标识
- **THEN** 系统忽略该标识或拒绝请求，并以服务端登录状态中的班级作为授权依据

### Requirement: 教师上传材料写入知识库
系统 SHALL 允许教师上传其所属班级的教学材料。上传成功后，系统 MUST 将材料解析结果写入该教师所属班级的知识库。

#### Scenario: 教师上传材料成功
- **WHEN** 教师上传符合系统限制的教学材料
- **THEN** 系统保存材料记录，解析材料内容，并将解析结果写入该教师所属班级的知识库

#### Scenario: 本班列表查到上传记录
- **WHEN** 教师成功上传材料并完成知识库写入后，本班用户请求材料列表
- **THEN** 系统返回该上传材料对应的列表记录

#### Scenario: 其他班级列表不可见
- **WHEN** 其他班级用户请求材料列表
- **THEN** 系统不得返回该教师上传材料的列表记录

### Requirement: 学生上传被拒绝
系统 MUST 拒绝学生上传材料。拒绝结果 MUST 表示权限不足，并且不得创建材料记录或知识库记录。

#### Scenario: 学生调用上传接口
- **WHEN** 已登录学生调用材料上传接口
- **THEN** 系统拒绝请求，返回权限不足结果，并且不写入材料记录或知识库记录

#### Scenario: 学生绕过前端入口上传
- **WHEN** 学生直接构造 HTTP 请求调用上传接口
- **THEN** 系统仍然在服务端拒绝该请求

### Requirement: 知识库写入失败不得产生可见记录
系统 MUST 在材料解析或知识库写入失败时避免发布不完整记录。失败材料不得出现在本班可用材料列表中。

#### Scenario: 解析失败
- **WHEN** 教师上传材料后解析失败
- **THEN** 系统返回失败结果或失败状态，并且本班材料列表不展示该材料为可用记录

#### Scenario: 知识库写入失败
- **WHEN** 材料已接收但知识库写入失败
- **THEN** 系统不得让该材料作为可用知识库记录被查询到
