## Purpose

本能力用于定义账号密码登录、教师/学生角色权限、受保护页面访问控制以及凭据和密钥的安全存储边界，确保后续业务功能建立在可信身份之上。

## ADDED Requirements

### Requirement: 账号密码登录
系统 SHALL 允许教师和学生使用账号密码登录。登录成功后，系统 MUST 建立服务端可验证的登录状态；登录失败时不得建立登录状态。

#### Scenario: 教师账号密码登录成功
- **WHEN** 教师提交正确账号和密码
- **THEN** 系统建立教师登录状态，并识别该用户的教师角色和所属班级

#### Scenario: 学生账号密码登录成功
- **WHEN** 学生提交正确账号和密码
- **THEN** 系统建立学生登录状态，并识别该用户的学生角色和所属班级

#### Scenario: 账号或密码错误
- **WHEN** 用户提交不存在的账号或错误密码
- **THEN** 系统拒绝登录，并且不建立登录状态

### Requirement: 受保护页面要求登录
系统 MUST 在未登录用户访问受保护页面时引导到登录页，且不得返回受保护页面内容。

#### Scenario: 未登录访问受保护页面
- **WHEN** 未登录用户访问材料列表、上传页面或其他受保护页面
- **THEN** 系统引导用户到登录页，并且不展示受保护页面内容

#### Scenario: 已登录访问授权页面
- **WHEN** 已登录教师或学生访问其角色允许的受保护页面
- **THEN** 系统允许访问，并根据服务端登录状态计算角色和班级权限

### Requirement: 密码安全存储
系统 MUST 仅存储密码哈希，不得存储、记录或返回明文密码。登录验证 MUST 使用已存储哈希进行校验。

#### Scenario: 创建或更新用户密码
- **WHEN** 系统保存用户密码
- **THEN** 持久化数据中只包含密码哈希，并且不包含明文密码

#### Scenario: 登录验证密码
- **WHEN** 用户提交登录密码
- **THEN** 系统使用密码哈希校验结果决定是否登录，不得通过明文密码比对完成验证

### Requirement: 服务端密钥管理
系统 MUST 仅从服务端环境变量读取密钥和敏感配置。系统 MUST 禁止将密钥写入前端代码、客户端响应或仓库明文配置。

#### Scenario: 服务端启动读取密钥
- **WHEN** 应用服务启动
- **THEN** 系统从服务端环境变量读取所需密钥和敏感配置

#### Scenario: 密钥缺失
- **WHEN** 必需密钥或敏感配置缺失
- **THEN** 系统拒绝以可用状态启动或返回明确的启动配置错误

#### Scenario: 客户端请求应用资源
- **WHEN** 客户端请求页面、脚本或接口响应
- **THEN** 系统不得向客户端暴露服务端密钥或敏感配置值
