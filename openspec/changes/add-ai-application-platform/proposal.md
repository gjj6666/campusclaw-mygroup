## Why

现有 CampusClaw 已支持知识库、可配置智能体、技能文件导入和 MCP，但用户需要一个能直接体验多个 AI 应用的平台，当前还缺少内置应用目录、提示词模板库和可安装的内置技能库。补齐这些入口后，用户能够在统一平台验证全部五项能力。

## What Changes

- 新增统一应用中心，内置课程答疑、解题引导、学习计划三个应用，提供简介、示例问题和一键开始会话；同时展示本班已启用的自定义智能体。
- 新增提示词模板库，包含上述应用的默认模板，支持变量填写、服务端预览、应用到智能体，以及教师维护本班自定义模板。
- 新增内置技能目录，至少包含解题引导、知识整理、学习计划；支持教师安装至本班、编辑与绑定。
- 把现有 .md/.txt 文件导入补齐为明确的上传、校验、保存和绑定流程，保留现有技能格式及 MCP 绑定校验。
- 复用现有资料管理、关键词/向量/混合检索、流式会话、外部 MCP 发现调用与审计，并增加统一导航、文档和五项能力验收用例。

## Capabilities

### New Capabilities

- `ai-application-catalog`: 内置多应用目录、一键启动及本班自定义应用入口。
- `prompt-template-library`: 内置与本班自定义提示词模板、变量渲染及应用。
- `skill-library-import`: 内置技能安装、文件上传校验及与应用绑定。

### Modified Capabilities

无。正式 openspec/specs 仍为空；本变更基于第 5、6 课未归档变更中已实现的智能体、技能、检索和 MCP 能力增量扩展，不替换其鉴权和隔离契约。

## Impact

新增目录配置、模板存储与 API、内置内容及前端应用中心；扩展现有 tutor_page.py、static/tutor.js、api.py、openapi.py、db.py 与迁移、apitest、README 和生成文档。保持单仓单 CampusClaw，继续使用 Python 标准库、SQLite、Qdrant 和同仓 mcp-server。

范围假设：沿用当前教学场景、教师/学生角色与班级边界；“个人项目”指该项目交付的平台，不引入注册、个人工作区、商城或新部署服务。外部工具通过现有 knowledge_search 与 MCP 接入满足，不新增任意代码插件执行。现有真实模型网关 TLS 故障作为独立验收限制保留，不能将替身测试标为真实模型成功。
