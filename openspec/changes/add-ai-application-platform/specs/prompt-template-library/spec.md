## Purpose

提供可复用的提示词模板能力，将课程应用的角色配置从手工重复编写扩展为可选择、填参、预览并保存的流程，帮助教师在保持班级隔离的前提下维护稳定且可验证的应用角色。

## ADDED Requirements

### Requirement: 内置与本班模板
系统 SHALL 至少提供课程答疑、解题引导、学习计划三个内置模板，展示名称、用途、正文和变量说明。教师 MUST 能创建、读取、更新、删除本班自定义模板，不能修改系统内置原件；学生 MUST 不能写入模板。自定义名称 MUST 为 1 至 64 字、班内唯一，正文 MUST 为 1 至 2000 字，重复或非法输入 MUST 返回可读 400。跨班自定义模板与不存在编号 MUST 返回一致 404，班级 MUST 只取自登录身份。

#### Scenario: 教师管理模板
- **WHEN** 教师创建包含学科与学习目标变量的本班模板
- **THEN** 模板可在本班读取和编辑，他班不可读取，学生写操作返回 403

#### Scenario: 内置原件保护
- **WHEN** 教师选择一个内置模板并按本班需求调整
- **THEN** 可以另存本班模板或应用生成文本，系统内置原件保持不变

### Requirement: 确定性变量渲染与应用
模板 SHALL 支持 {{subject}}、{{audience}}、{{goal}} 形式的命名变量；每个值 MUST 为 1 至 300 字文本。系统 MUST 在服务端校验变量、预览渲染结果，再由教师显式应用并保存到智能体角色。缺失值、额外变量、未知占位符、未配对占位符或渲染结果超过 2000 字 MUST 返回可读 400，不修改已有配置。渲染 MUST 只替换文本，MUST 不执行表达式、代码或二次展开。应用后 MUST 保存当时文本快照，后续修改或删除模板不追溯改变旧应用。

#### Scenario: 预览并保存角色
- **WHEN** 教师选择模板、填写学科/受众/目标并预览，再保存到本班智能体
- **THEN** 预览与保存的角色文本一致，后续提问使用该角色

#### Scenario: 非法变量与表达式
- **WHEN** 教师提交缺失变量、表达式占位符或超长渲染结果
- **THEN** 请求失败且原角色不变，任何输入均不触发代码执行

#### Scenario: 模板更新后的独立性
- **WHEN** 教师应用模板后修改或删除原模板
- **THEN** 已保存角色保持原值，只有再次显式应用并保存才发生变化
