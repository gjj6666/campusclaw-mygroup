## Purpose

为课程验收提供与处理器同源的接口契约、浏览器 Swagger 实际试调和可重复的接口测试，通过返回内容与数据库核验、真实同伴日志及密钥保护确保实现可追溯且结论真实。

## ADDED Requirements

### Requirement: 注解同源文档与Swagger

系统 SHALL 无登录提供 `/openapi.json` 和 `/swagger`。OpenAPI MUST 由处理器注解生成，包含所有主要接口的路径、方法、参数、入参出参结构、错误码和 Bearer 登录要求；登录与健康检查 MUST 标为无需认证。Swagger MUST 可输入 Bearer 令牌并实际发送主要请求，包含流式协议说明。文档路由 MUST 优先于业务路由匹配。

#### Scenario: 文档实际试调
- **WHEN** 浏览器打开 Swagger，登录取得令牌并调用检索、配置、会话接口
- **THEN** 请求符合文档并返回约定内容，学生写配置返回文档所示 403

#### Scenario: 注解变动
- **WHEN** 处理器注解改变接口字段或路径
- **THEN** 生成文档随之改变，检查可发现路由、注解不一致或遗漏

### Requirement: URL组织的接口测试和HTML报告

仓库 SHALL 提供 `apitest/cases/<URL路径>/<METHOD>.py`，每个接口方法一份脚本及 `apitest/run_all.py` 一键入口。运行 MUST 生成包含用例、断言、成功失败和脱敏证据的 HTML 报告，失败 MUST 返回非零退出码，报告 MUST 被 Git 忽略。至少覆盖登录、检索、智能体提示词及绑定、技能、创建读取会话与发送消息，MUST 校验响应内容及数据库数据一致，禁止仅断言状态码。

#### Scenario: 一键执行并核验落库
- **WHEN** 运行接口测试入口
- **THEN** 每个脚本经真实 HTTP 请求验证约定字段、权限及数据库持久化，消息正文等于所有 delta 拼接，输出未跟踪的 HTML 报告

#### Scenario: 隔离与解析边界
- **WHEN** 执行跨班、他人会话、缺令牌、学生写入、技能非法文件、重复名称及无证据用例
- **THEN** 响应体、状态和数据库变化符合规约，报告不含密码、令牌或网关密钥

### Requirement: 同伴交叉证据与配置保护

系统交付 SHALL 包含同伴验证说明及仓库记录位置，覆盖会话归属、智能体隔离及停用、班级边界、技能开关即时生效四项。记录 MUST 包含真实同伴账号角色、时间、请求与脱敏响应或截图及结论；未获得同伴证据 MUST 明示待完成，禁止用自动化替身冒充。真实密钥 MUST 仅在本机 `.env`，不入 Git、数据库或镜像。

#### Scenario: 尚无同伴操作
- **WHEN** 只有本地自动化测试结果
- **THEN** 同伴记录四项标为待同伴执行，不宣称课程交叉验收完成

#### Scenario: 交付检查
- **WHEN** 检查 Git 跟踪文件、报告、数据库及镜像构建范围
- **THEN** 均不含真实密钥，测试报告未提交，既有第4课代码与数据得到保留
