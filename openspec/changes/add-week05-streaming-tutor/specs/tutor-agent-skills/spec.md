## Purpose

为教师提供本班智能体、角色提示词与解题技能的配置能力，通过技能文件校验、班内唯一命名与材料绑定控制学生会话的回答行为，使每次提问使用最新配置且不泄露其他班级资源。

## ADDED Requirements

### Requirement: 智能体与绑定管理

系统 SHALL 允许已登录用户列出及读取本班智能体，仅允许教师创建、更新智能体与其技能和材料绑定。名称 MUST 为 1 至 64 字，角色提示词 MUST 不超过 2000 字；留空或全空白时 MUST 使用默认助教角色。绑定 MUST 仅接受本班技能及可用材料，整次更新原子生效。智能体及材料 MUST 具有可用于过滤的学科字段；未指定学科时使用“通用”，通用智能体不作学科排除。

#### Scenario: 教师更新角色与两类绑定
- **WHEN** 教师提交合法角色及本班技能和材料编号
- **THEN** 读取智能体能获得与数据库一致的角色、启用状态、学科及两类绑定

#### Scenario: 学生写入
- **WHEN** 学生请求任意智能体或绑定写操作
- **THEN** 返回 403 且不修改数据库

#### Scenario: 非法或跨班配置
- **WHEN** 教师提交超长字段，或不存在、跨班的技能或材料编号
- **THEN** 超长字段返回可读的 400，跨班与不存在编号返回相同的 404，既有配置和绑定均不部分更新

#### Scenario: 提示词留空
- **WHEN** 教师保存空白角色提示词后学生提问
- **THEN** 系统使用默认助教角色构造系统消息

### Requirement: 技能文件校验和班级隔离

系统 SHALL 提供技能列表、按编号读取、创建、更新与删除，写操作 MUST 仅教师可用；班内名称 MUST 数据库唯一。技能文件 MUST 不超过 8000 字，包含“名称”“适用条件”“启用”字段，首个空行后具有非空正文；名称 MUST 为 1 至 64 字，适用条件 MUST 为 1 至 500 字，启用 MUST 为“是”或“否”。可选“工具”字段只接受 `knowledge_search`。重复字段、缺字段、未知字段、非法工具及长度不合法 MUST 返回可读的 400，且不落库。

#### Scenario: 文件缺字段或重复字段
- **WHEN** 文件缺少必填字段、重复名称、工具非法或没有正文
- **THEN** 返回 400 并说明字段与原因，不创建或修改技能

#### Scenario: 同名与跨班直取
- **WHEN** 教师提交班内已有技能名，或用户读取他班技能编号
- **THEN** 同名返回 400；他班编号与不存在编号返回完全一致的 404

#### Scenario: 删除已绑定技能
- **WHEN** 教师删除本班技能
- **THEN** 该技能及相关绑定删除，既有会话下一次提问不再使用该技能

### Requirement: 可维护的解题引导技能

系统 SHALL 提供教师可维护和绑定的至少一条解题引导示例，其正文 MUST 要求分步提示、提问和检查学生思路，禁止直接给出最终答案；教师显式保存及启用后才参与路由。

#### Scenario: 学生请求最终答案
- **WHEN** 适用的解题引导技能被选中且学生要求直接给答案
- **THEN** 回答呈现下一步提示或思考问题，不直接输出最终答案
