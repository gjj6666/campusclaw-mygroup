## Why

当前 CampusClaw 已具备应用、提问附件、技能与 MCP，但应用切换、会话、资料浏览和教师配置的层级不清晰，长表单影响日常使用。参考用户提供的六张系统截图，需要形成独立的学生工作区、资料库及教师管理台，并按用户确认加入本人跨会话复用的个人资料库。

## What Changes

- 学生工作区采用“全局导航—应用/会话列表—内容区”布局，加入助手欢迎页、快捷问题、最近对话标题与时间；保留输入框旁添加技能、资料及双角色上传。
- 资料库按学科分组，支持标题筛选、列表/网格切换与安全的 Markdown/纯文本阅读；整合本班共享资料和我的个人资料。
- 教师和学生均可上传个人资料、从本班共享资料保存个人副本，或将本人原会话资料显式复制到个人库；本人可在本班不同会话中选择使用，原会话附件不自动扩权。
- 教师管理独立为 `/admin`，提供学生（只读名单）、资料、智能体、技能、MCP 分栏；提示词模板归入智能体配置，提供文件上传、清晰状态与独立保存反馈。
- 教师可配置本班资料分段策略、预览片段，并对指定资料执行重建索引；设置变化不自动重建全班资料，原文引用保持可回溯。
- 补齐 MCP 服务器编辑、移除操作，修改连接配置后须重新发现工具；保留已有发现、绑定鉴权与调用审计。
- 默认延续暖色米白主题，主色调整为暖砖红，提供可记忆的深浅主题切换及移动端折叠导航。
- 本次不实现错题本、智能批改、自主学习，界面不放置这些模块的可点击占位入口；不新增账号开通、密码重置或外部资源市场。

## Capabilities

### New Capabilities

- `campus-workspace-navigation`: 三层工作区、欢迎与快捷提问、最近会话、主题及响应式导航。
- `personal-material-library`: 班级资料分类阅读、本人个人资料存储、显式复制及跨会话选择。
- `teacher-management-console`: 教师独立管理台、分栏操作、共享技能/应用配置及 MCP 编辑移除。
- `class-material-index-policy`: 本班分段策略、预览、索引状态和指定资料重建。

### Modified Capabilities

主规约目录尚无已归档能力。此变更新增规约，并显式扩展 `add-question-attachments-warm-ui`：材料引用新增 personal 来源，允许独立个人库跨本人本班会话使用；upload 来源仍仅在原会话有效。重构暖色工作区并将教师长面板迁往独立管理台，不改变共享写权限。

## Impact

涉及 tutor_page.py、static/tutor.js、warm.css、web.py、api.py、attachments.py、tutor.py、services.py、rag.py、chunking.py、vector_store.py 及 MCP 管理模块；新增个人资料、管理台与班级索引策略模块和增量数据库迁移。同步更新 OpenAPI、单元/接口/SSE/浏览器验收与文档。

保留单仓 Compose、Bearer、班级取自会话、旧 JSON 接口和已有数据；所有新增越权资源访问统一 404，教师专属接口对学生返回 403。真实模型网关此前失败的验收状态继续单独记录，本次不改变 TLS 或密钥配置。
