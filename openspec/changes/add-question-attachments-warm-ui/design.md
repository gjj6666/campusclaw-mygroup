## Context

当前 tutor_page.py 与 static/tutor.js 将应用卡片、对话及大量教师配置放在同页，技能和资料仅从应用长期绑定读取。orchestration.prepare 选择一个触发技能，并对绑定资料检索；api.messages_send 负责 SSE、引用校验和消息持久化。共享资料上传、技能导入均限定教师。MCP 已有按班级发现校验及调用审计。messages 尚无上下文快照列，公共 page_css 和 tutor 样式均偏冷色。

用户确认教师和学生都可在提问时上传。现有共享模型不能直接开放给学生，否则学生上传会进入全班可见范围。本变更新增独立、按本人会话隔离的附件路径。旧规约关于应用绑定路由的行为保留为缺省分支；显式上下文是本变更引入的新分支。

## Goals / Non-Goals

目标：提问框直接选择/上传技能与资料，当前问题生效；双角色上传且保护私有内容；来源和上下文可回看；MCP 保持鉴权和审计；暖色、对话优先、移动端可用。

非目标：PDF/Word/图片解析、多技能合并、附件代码执行、私有向量库、学生修改班级共享配置、自动将附件公开、改变既有模型配置与 TLS 策略。

## Decisions

### 1. 独立会话附件与增量迁移

新增 conversation_attachments：id、class_id、user_id、conversation_id、kind、filename、content、解析后的技能元数据、created_at。附件不可变；标签移除不删除记录，保证历史引用可读。通过会话父资源统一校验本人及班级。新增 messages.context JSON 文本列，缺省 {}，保存模式、来源、名称和标识快照；不存密钥。不改动共享表权限，不自动建知识条目。

新增 GET/POST /api/conversations/{id}/attachments，GET /api/conversations/{id}/attachments/{attachment_id}；列表与详情不向其他会话开放。现有消息接口的可选 context 引用为 {source: shared|upload, id: number}，skill 为一个引用/null，materials 为引用列表。新增会话可用共享选择接口或扩展已有只读列表，仅返回必要名称、简介与标识，不暴露教师私有配置。所有接口补充 OpenAPI。

### 2. 精确的本轮选择与兼容缺省路径

两个字段独立处理：缺省保留对应应用行为；skill:null 禁用本轮技能，显式技能直接执行，不走触发词打分；materials:[] 关闭本轮检索，显式列表替换默认资料范围。最多三份资料（共享与上传合计），重复拒绝。旧客户端及无 context 的请求完全保留原逻辑。显式共享资料不受应用学科过滤，因为学科不是授权边界；仍要求同班、ready。

UI 初始显示“自动匹配”技能及默认资料范围；用户编辑资料后提交最终显式列表，添加资料时保留已有默认选择，默认范围超过三份时提示用户精简后再提交显式选择。成功发送恢复默认，失败保留草稿；会话切换清理可见草稿选择并重新加载该会话附件，避免误用。上传记录可在原会话再次选择，但不自动用于下一轮。

### 3. 文本附件与提示构造

上传仅接受 UTF-8 .md/.txt，32 KiB 上限；技能使用原解析器并限制正文 8000 字符，资料正文 12000 字符；每轮上传资料总计 18000 字符。浏览器使用严格 UTF-8 解码，服务端再次检查。客户端不是验证边界；格式/超限/不可用状态返回 400，所有越权与缺失返回 404，验证先于模型和工具请求。

小型私有资料直接作为有明确边界的用户消息数据，不依赖向量索引或嵌入网关；共享资料沿用原 RAG（最多四条检索结果）。私有上传技能作为用户级指示，不能进入系统角色；教师共享技能保持现有配置语义。MCP 工具声明沿用解析与 resolve，上传时检查、调用时再检查；断开产生 denied meta/审计，不假装成功。文件内容与文件名以文本渲染。

### 4. 统一来源与历史快照

共享检索结果和每份私有资料依次编号 S1…，沿用现有引用校验器。来源补充 kind、attachment_id、受保护详情 URL；共享 material_id 保持兼容。SSE meta 增加 context，消息历史解析新增列并展示选择标签，旧记录默认空快照。保留既有限制长度的对话历史，不承诺移除附件后模型完全忘记历史文本。

### 5. 对话工作区和暖色变量

应用切换、会话列表压缩到导航/侧栏，聊天占据主区域；教师配置收进次级可展开面板。输入框边提供技能、资料和上传控件、预览、状态与标签；上传技能/资料类型明确可选。保留现有管理功能及角色保护。

公共 page_css 和 tutor 使用同一套 CSS 变量：米白 #fbf6ee、卡片 #fffdf8、暖橙 #b95f35、深棕 #44352d、暖灰边框 #e8d9c7。按钮文字和 hover 色以实际对比度测量后调整到合格值，避免只改变背景而遗留冷色组件。错误红、焦点环、加载提示独立可辨。390 像素布局折叠导航、标签换行，避免横向溢出。

## Risks / Trade-offs

- 私有文本直送增加 token → 固定文件及单轮字符上限，超限显式拒绝。
- 用户技能包含提示注入 → 用户角色放置、系统规则保持、工具调用服务端再鉴权；不将文本隔离误称为模型绝对安全保证。
- 手动技能与自动路由意图冲突 → 显式选择优先，标签明确显示状态，缺省行为不变。
- 历史快照与文件生命周期 → 文件不可变并保留，取消选择仅影响当前草稿；删除/配额策略留待独立变更。
- 模型网关已有 TLS EOF → 使用替身模型验证确定性链路，真实 Compose 检查单独记录；原真实网关验收仍保持待完成。

## Migration Plan

先备份运行数据库，使用现有增量迁移方式添加表和缺省列；启动和旧库迁移测试确保历史数据完整。后端先兼容 context 缺省，再接入前端。回滚时恢复旧应用和备份数据库；不丢弃原共享表。运行针对权限、上下文、SSE、MCP 的单元与接口测试，生成忽略提交的 HTML 报告，重建 Compose 后进行教师/学生与桌面/移动浏览器验收，更新测试说明。
